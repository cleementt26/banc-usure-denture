# Comprendre le banc d’usure de denture

Site pédagogique statique en français, destiné à expliquer la chaîne mécanique, les composants et les réglages du banc développé en 1997.

## Contenu

- Schéma interactif de principe, animation volontaire et limitée à 15 secondes.
- Cinq étapes de fonctionnement et cinq vues techniques sélectionnables.
- Explication illustrative du rapport vitesse/couple des poulies.
- Vidéo de démonstration manuelle de 17,6 secondes, sans audio.
- Données moteur et distinction explicite entre observations, documentation et hypothèses.

Les sources de l’analyse sont 37 photos, une vidéo, « Descriptif banc.docx », « Banc usure denture.pptx » et les courbes constructeur Parvex RX. Les documents internes bruts ne sont pas inclus. Les caractéristiques indiquées ne constituent pas une validation de remise en service.

## Aperçu local

Servir ce répertoire avec un serveur HTTP statique, par exemple `python -m http.server 8080`, puis ouvrir `http://localhost:8080`.

## Publication

GitHub Pages : déployer depuis la branche `main`, répertoire racine `/`. Aucun outil de compilation ni service externe n’est nécessaire.

## Médias

Les photos ont été redimensionnées et leurs métadonnées retirées. Le fichier vidéo H.264 est adapté à une lecture web avec chargement progressif. Les médias proviennent des éléments fournis pour cette visite.
